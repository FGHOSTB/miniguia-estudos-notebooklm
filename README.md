# miniguia-estudos-notebooklm
Este projeto constrói um Caderno Temático (Hands-on Cookbook) no NotebookLM para consulta rápida de comandos e sintaxes em Algoritmos, Git, MongoDB, MySQL e SQL. O repositório centraliza guias práticos, documenta o processo de Engenharia de Prompts (troubleshooting) e entrega um miniguia de estudos para acelerar o desenvolvimento no dia a dia.
